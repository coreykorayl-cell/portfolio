# V1 migration handoff

Source: https://corey-lightner-98andgreat.coreykorayl.chatgpt.site/

## Send this to the site builder

> Export the complete latest source of “Corey Lightner — Creative Producer” as a ZIP or accessible Git repository. Include all pages/routes, HTML/components, styles, scripts, public assets, local fonts, project data, package.json and lockfile, build configuration, and README. Include the source files, not only a compiled build or screenshots. Provide a route and link inventory plus any redirects. Identify third-party integrations and environment variable **names only**; exclude secret values, tokens, credentials, node_modules, and Git history. Bundle original media where permitted, and identify external media or fonts that cannot be bundled. Include desktop and mobile screenshots and describe hover, click, navigation, and animation behavior. Do not change or unpublish the current site.

## Required to faithfully port v1

1. **Source export:** ZIP or repository above. If full export is unavailable, provide HTML/CSS/JS and a downloaded asset folder; screenshots alone cannot recover source or behavior.
2. **Original assets:** Project covers and hover previews, photography, video files/posters or embed URLs, logos, favicon, social preview artwork, and fonts with usage rights. Include file-to-project mapping, crop/focal-point preferences, and alt text where available. Avoid temporary signed asset URLs.
3. **Project content:** Exact titles, ordering, descriptions, Corey’s roles, clients/credits approved for publication, years, case-study copy, and destinations. Specify whether each card opens a page, modal, video, or external link.
4. **Real destinations and content:** The exact “Enter 98&Great” URL; Journal entries and route names; Prints catalog and purchase links; Resources files/links; Support destination. Confirm what is live versus planned. If these live elsewhere, URLs are enough for the initial links.
5. **Design and behavior reference:** Desktop and mobile screenshots (full page plus card-hover states), exact fonts/colors if not in source, navigation behavior, transitions, and responsive differences.
6. **Other site details:** Contact email/social links to display, existing page titles/descriptions, analytics or forms if any, and a list of existing routes that need preserving or redirecting. No passwords or API keys in chat.

## After the export arrives

- Compare source with this scaffold; retain portable HTML/CSS where possible and remove builder-only hosting dependencies.
- Import real content and locally owned media, recreate necessary interactions, and preserve route/link behavior.
- Replace all placeholder graphics, notes, and provisional copy; confirm contact and studio destinations.
- Validate mobile/desktop layout, keyboard operation, links, image alt text, media loading, and build output.
- Review on a temporary hosting URL, then connect the domain only after approval.

## Not needed yet

Registrar access, DNS changes, paid hosting, a CMS, databases, and secret credentials. Hosting account/repository selection and DNS access become relevant after content review.
